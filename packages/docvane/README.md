# docvane

A template engine for Word, PowerPoint and Excel files, with one syntax for DOCX, PPTX and XLSX. Templates and data are treated as untrusted. MIT license, ESM only.

**Status:** early development. This version contains only the project skeleton and has no template features yet.

XLSX templates and low-level OOXML handling come from [xlvane](https://github.com/DevXord/xlvane), the sister project for working with spreadsheet files in code.
