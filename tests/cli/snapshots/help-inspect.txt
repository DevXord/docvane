tplvane inspect - See which data a template needs

Usage:
  tplvane inspect <template> [options]

Lists the fields of the data that a Word, PowerPoint or Excel template needs, its loops and
conditions, and every tag with its place. --schema prints the JSON Schema of the data instead.
Problems of the template are listed, each with its place and a hint.

Options:
      --schema                  Print only the JSON Schema of the data
      --delimiters "<s> <e>"    Tag delimiters, start and end, such as "{{ }}" or "[[ ]]" (default "{ }")

Global options:
      --json                    Print one JSON document to stdout (node_modules/tplvane/docs/cli-json.md)
  -q, --quiet                   Print only results and errors
      --verbose                 Print the stack trace of internal errors
  -h, --help                    Show help for the command

Examples:
  tplvane inspect offer.docx
      Data fields, sections and tags of the template
  tplvane inspect offer.docx --schema
      The JSON Schema of the data
  tplvane inspect offer.docx --json
      The whole result as JSON

Exit codes: 0 success, 2 usage error, 3 input, file or template error.
Related: tplvane validate, tplvane render
